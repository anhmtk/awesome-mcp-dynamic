# Security policy

This repository is a curated list and a draft spec. It does not run an MCP server and it does not hold API keys.

## Listings

If a listed project tells agents to submit code and then executes that code, open an issue titled `Unsafe listing:` with the URL and the sentence that says so. The maintainer will remove the listing or correct the description.

## Spec

If the draft in [SPEC.md](SPEC.md) can be read as permission to run client-authored tools, open an issue on the spec. That reading is a bug in the text.

## Someone else's server

Report a vulnerability in a listed product to that product's maintainers. This repository cannot patch AgentShare or any other server.

## Private reports

Use [GitHub security advisories](https://github.com/anhmtk/awesome-mcp-dynamic/security/advisories/new) when the report should stay private. Email [admin@agentshare.dev](mailto:admin@agentshare.dev) if you cannot use advisories.
